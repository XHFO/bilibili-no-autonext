# 哔哩哔哩 · 关闭自动连播

版本 1.2.1，适用于 Chrome 119 及更新版本，默认开启。插件会自动点击播放器结束面板上的「取消连播」，并关闭可识别的已开启连播开关，同时拦截视频结束通知。手动点击下一集、推荐视频或重新播放仍然可用。

新增抽屉播放支持：不再依赖地址栏是否进入 /video/，检测首页抽屉、内嵌播放器及开放 Shadow DOM 中的取消连播按钮。BewlyBewly 实际环境仍需验证；无法读取封闭 Shadow DOM 或非匹配来源的内嵌页面。

弹窗采用 Chrome 风格的滑动开关，自动跟随系统浅色 / 深色模式，并支持键盘操作。

## 更新旧版

用新版文件替换原插件文件，或移除旧版后重新加载新版文件夹。在扩展管理页面确认版本为 1.2.1，然后刷新所有已打开的视频页面。仅重新打开插件弹窗不会更新页面上的旧脚本。

## 安装

1. 如果下载的是 ZIP，请先解压。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的文件夹。
5. 刷新之前已经打开的哔哩哔哩视频页面。

点击 Chrome 工具栏的扩展图标，可开启或关闭屏蔽。开关会同步到已经打开的哔哩哔哩页面，无需再次刷新。

## 范围与限制

- 关闭连播开关时，网站可能记住该偏好。关闭插件后，如需连播，请在播放器中手动重新开启。
- 不阻止首次打开视频时自动播放，也不处理直播或播放器的单视频循环模式。
- 拦截结束通知可能同时影响网站的播完提示、结束推荐面板或播完统计。
- 仅在 www.bilibili.com、player.bilibili.com 及其来源匹配的内嵌页面上运行；不申请浏览历史、下载或其他站点访问权限，无远程代码，不收集或上传数据。
- 已检查脚本语法、模拟结束事件及倒计时取消逻辑；尚未在登录后的哔哩哔哩实际播放器中验证。网站如果更改按钮文案或播放器结构，可能需要更新插件。

## 卸载

在 `chrome://extensions/` 找到该插件，点击「移除」。

## 下载

从 [Releases](https://github.com/XHFO/bilibili-no-autonext/releases) 下载插件安装包，解压后按上述步骤加载。此项目尚未发布到 Chrome 网上应用店。

## 项目结构

- `manifest.json`：Chrome 扩展配置。
- `guard.js`：拦截原生视频结束通知。
- `settings.js`：同步开关设置、检测并取消连播倒计时。
- `popup.html`、`popup.css`、`popup.js`：插件开关界面。

项目不需要构建，修改文件后在 Chrome 扩展管理页点击重新加载，再刷新哔哩哔哩页面。
